# Documentation

This directory is the home for the project's documentation assets.

## Images

* [egm_sketch.png](images/egm_sketch.png): A conceptual sketch of how the EGM library relates to an ABB robot controller, showing the communication links and the role of the optional *StateMachine Add-In* in the controller's RAPID program and system configuration.
* [statemachine_addin_sketch.png](images/statemachine_addin_sketch.png): A conceptual sketch of the RAPID program's execution flow provided by the optional *StateMachine Add-In*, where each motion task receives its own state machine instance.
